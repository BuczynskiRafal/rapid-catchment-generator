# Security Policy

## Supported Versions

Security fixes are applied to the latest `2.0.x` release line:

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Rapid Catchment Generator, please report it privately through
[GitHub Private Vulnerability Reporting](https://github.com/BuczynskiRafal/rapid-catchment-generator/security/advisories/new)
rather than opening a public issue.

Please include:

- A description of the vulnerability and its potential impact.
- Steps or a minimal proof of concept to reproduce the issue.
- Affected version(s) and operating system.
